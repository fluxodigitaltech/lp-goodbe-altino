Landing page da unidade **GoodBe Altino Arantes** (Vila Clementino, São Paulo/SP).
HTML único portátil (fotos e logos embutidos em base64), servido por nginx:alpine.

- Deploy: Easypanel Server 1, projeto `site`, serviço `lp-goodbe-altino` (build por Dockerfile, autoDeploy).
